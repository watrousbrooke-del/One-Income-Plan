These 31 files are your website, exactly as it is live on oneincomeplan.com
on October 30, 2026. They were checked line by line against the live site.

You never need to touch these to run your business. They are your backup,
and the master copy if a page ever needs rebuilding.

HOW A PAGE GOES INTO SHOWIT
1. In Showit, open the page.
2. Click the page name, then Advanced Settings, then Custom Head HTML.
3. Paste the whole file in, replacing what is there.
4. Save, then Publish.

The file "site-wide-head-code.html" goes in Site Settings, Integrations,
Custom Code (head, all pages). It holds the cookie banner and the share image.
